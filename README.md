# Azure Functions + Application Insights Labs

Hands-on Azure Monitor and Application Insights labs using Azure Functions and .NET 8.

## Labs

### Lab 1 - Telemetry Health Check
- Create Application Insights
- Create Azure Function App
- Generate telemetry
- Validate Requests
- Validate Traces
- Validate Exceptions
- Validate Live Metrics
- Capture operation_Id for correlation

### Lab 2 - Known Failure Investigation
- Correlate telemetry
- Investigate failures
- Reconstruct transaction timelines
- Determine failure boundaries

## Technologies

- Azure Functions (.NET 8 Isolated)
- Application Insights
- Azure Monitor
- Log Analytics
- Kusto Query Language (KQL)
